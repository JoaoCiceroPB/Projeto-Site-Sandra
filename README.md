# ⚖️ Landing Page - Escritório de Advocacia (Site Sandra)

Uma landing page moderna, elegante e responsiva desenvolvida para apresentação de serviços de advocacia, facilitando o contato direto de clientes através da web.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layout responsivo e animações.

---

## ✨ Funcionalidades

- Layout adaptável para dispositivos móveis (smartphones, tablets e desktops).
- Seção sobre as áreas de atuação da advogada/escritório.
- Formulário direto para agendamento de consultas ou contato rápido.
- Botão flutuante para atendimento via WhatsApp.
